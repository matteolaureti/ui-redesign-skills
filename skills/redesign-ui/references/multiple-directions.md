# Multiple redesign directions

Use this guidance only when the user requests several concepts, alternatives, variants, or design directions.

## Output rule

Generate each redesign as a separate full-size output image.

Never place multiple concepts in one image unless the user explicitly requests a contact sheet or comparison board.

## Two kinds of diversity are required

Each concept should differ in both:

1. **structural direction** — composition, navigation, hierarchy, grouping, density, component architecture, disclosure;
2. **visual art direction** — palette, typography personality, surface language, imagery strategy, icon treatment, chart styling, visual mood, depth, and brand-color expression.

Structural diversity alone is not enough. Visual diversity alone is not enough.

Do not keep every concept inside the same palette, typography family, surface language, imagery strategy, or visual mood simply because those elements appear in the reference screenshot.

## Structural variation

Useful axes include:

- global composition;
- navigation architecture;
- information hierarchy;
- density;
- grouping;
- primary focal point;
- component model;
- visual rhythm;
- disclosure of secondary information;
- placement of actions and status.

Before generating another concept, avoid reusing the same page skeleton, navigation architecture, focal point, and component arrangement from the previous one.

## Visual variation

Use `visual-directions.md` to push concepts into genuinely different art-direction families when appropriate.

A new direction may change:

- light, dark, warm, cool, tinted, or high-contrast palette strategy;
- restrained enterprise versus editorial, premium, minimal architectural, media-led, brand-forward, or data-first character;
- typography hierarchy and personality;
- photography, previews, thumbnails, maps, product imagery, content covers, or other meaningful visual assets;
- border/divider/shadow/elevation strategy;
- amount of texture, grain, ambient depth, or background treatment;
- iconography and data-visualization language;
- how strongly the original brand color is used.

Color, font, radius, shadow, or accent changes alone do not make a new direction, but keeping all of them identical across every direction also limits exploration unnecessarily.

## Preserve invariants

Across all directions, keep stable whatever the user has not asked to change, especially product purpose, important functionality, required content, truly distinctive brand assets, and device category.

Preserve the identity of the product without treating its current visual implementation as untouchable.

## Exploration

Choose directions that make sense for the product rather than mechanically following a preset list.

Every concept should still be coherent and realistically usable; diversity is not a reason to introduce random experimentation.

Before finalizing each concept, ask: **Does this feel like a genuinely different product-design direction, or merely the same art direction rearranged into another layout?** If it is the latter, push the visual language farther while preserving product coherence.
