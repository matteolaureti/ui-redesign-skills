# Multiple redesign directions

Use this guidance only when the user requests several concepts, alternatives, variants, or design directions.

## Output rule

Generate each redesign as a separate full-size output image.

Never place multiple concepts in one image unless the user explicitly requests a contact sheet or comparison board.

## Diversity

Make the concepts differ in meaningful design decisions, not just styling.

Useful axes of variation include:

- global composition;
- navigation architecture;
- information hierarchy;
- density;
- grouping;
- primary focal point;
- component model;
- visual rhythm;
- disclosure of secondary information;
- use of imagery when appropriate.

Color, font, radius, shadow, or accent changes alone do not make a new direction.

## Preserve invariants

Across all directions, keep stable whatever the user has not asked to change, especially product purpose, important functionality, required content, brand constraints, and device category.

## Exploration

Choose directions that make sense for the product rather than mechanically following a preset list. Depending on the task, useful contrasts might include familiar versus structurally rethought, compact versus spacious, data-first versus task-first, integrated surfaces versus modular panels, or restrained versus brand-forward.

Before generating another concept, avoid reusing the same page skeleton, navigation architecture, focal point, and component arrangement from the previous one.

Every concept should still be coherent and realistically usable; diversity is not a reason to introduce random experimentation.
