# Contributing

Contributions are welcome.

This repository intentionally keeps the redesign guidance in a **single monolithic skill**:

```text
skills/redesign-ui-from-screenshots/SKILL.md
```

The goal is to improve that one skill through real usage tests rather than split its design judgment across multiple routed reference files.

## Contribution principles

Useful changes should improve concrete redesign behavior, for example:

- stronger dashboard art direction;
- better landing-page composition;
- better mobile/iOS handling;
- more meaningful visual diversity across multiple concepts;
- stronger imagery guidance;
- improved preservation of product meaning;
- better anti-AI-slop rules;
- better image fidelity and realism.

Avoid turning individual visual styles such as “glass”, “blue”, “minimal”, or “dark” into separate skills.

## Required output rule

Any contribution must preserve:

> **One output image = one redesign.**

If several concepts are requested, they should be separate full-size output images unless the user explicitly requests a combined comparison format.

## Pull requests

Explain:

- what redesign behavior the change improves;
- what real screenshot or prompt exposed the problem;
- how the change affects generated results;
- whether it introduces any new trade-offs.

Prefer evidence-driven changes based on repeated image-generation tests.
