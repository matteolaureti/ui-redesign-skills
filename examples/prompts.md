# Example prompts

The examples below assume the `redesign-ui-from-screenshots` skill is installed.

## Dashboard — one redesign

> Use $redesign-ui-from-screenshots to completely redesign the attached dashboard. Preserve its product purpose, important information and functionality, but rethink the hierarchy, layout, navigation, density, typography, surfaces and component structure. Generate one complete redesign image.

---

## Dashboard — eight different directions

> Use $redesign-ui-from-screenshots to create 8 genuinely different redesign directions for the attached dashboard. Preserve the same product purpose and important functionality across all concepts, but vary the composition, hierarchy, navigation, density, component architecture, typography, surfaces and visual language. Generate 8 separate full-size output images, one redesign per image.

---

## Landing page

> Use $redesign-ui-from-screenshots to completely redesign the attached landing page. Keep the product and brand recognizable, but rethink the narrative, hero, section structure, product presentation, social proof and conversion hierarchy. Avoid generic SaaS landing-page patterns. Generate one redesign image.

---

## iOS / mobile app

> Use $redesign-ui-from-screenshots to redesign the attached mobile app screen. Preserve the task and important content, but rethink navigation, hierarchy, controls, typography and visual language where useful. Generate one redesign image.

---

## Single component

> Use $redesign-ui-from-screenshots to redesign only the highlighted component in the attached screenshot. Improve its information hierarchy, structure and visual treatment while keeping it compatible with the surrounding product. Do not redesign the entire page. Generate one component redesign image.

## Natural-language invocation

Explicit `$redesign-ui-from-screenshots` invocation is useful for controlled tests, but the skill description is also designed for implicit discovery when the user clearly asks for a visual redesign of an existing UI screenshot.
